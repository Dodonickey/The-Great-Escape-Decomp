# The Great Escape Decompiled

A decompilation of a **lost, abandoned beta** originally made by Traplight Games. It was showcased in [this video](https://www.youtube.com/watch?v=2n4rxrZSvFM&t=182s) around the **3:00 mark**. The version shown in the video differs from this decompilation.

This game was decompiled from an old TestFlight build of the game.

> **📦 Game Version: `0.6.2`**

**[⬇️ Download the 32-bit IPA](https://archive.org/download/traplight-great-escape/Great%20Escape%21_%28com.Traplight.Farm%29_0.6.2.ipa)**

# 🛠️ Unity Setup

For this project, I'd recommend using **Unity 4.7.2f1**, since that is the version I used.

> ⚠️ **Using later versions may cause compatibility issues. Opening the project in earlier versions may also cause compatibility issues.**

You can get previous Unity versions here:

https://forum.unity.com/threads/early-unity-versions-downloads.1483758/

# 🎮 Editor Controls

Assuming you are on PC, here are the controls for the editor:

| Key            | Action   |
| -------------- | -------- |
| **A**          | Zoom in  |
| **Z**          | Zoom out |
| **Left Shift** | Draw     |
| **Left Alt**   | Erase    |

> That's all the important ones for now.
